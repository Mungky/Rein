● Semua endpoint auth return 503. Dari kode, 503 di dependencies.py:86 hanya
  terjadi saat SUPABASE_JWT_SECRET tidak diset.

  Alurnya:
  1. User login di frontend (langsung ke Supabase) → berhasil, dapat JWT token
  2. Frontend kirim JWT ke /api/auth/me
  3. Backend parse JWT header → alg = HS256
  4. Cek settings.supabase_jwt_secret → kosong → 503 "Supabase JWT secret is not
   configured"

  Solusi: Di Coolify → Environment Variables, tambahkan SUPABASE_JWT_SECRET.

  Cara dapat nilainya:
  1. Buka Supabase Dashboard → project kamu
  2. Settings → API → JWT Secret (bukan anon key, bukan service role key — ini
  secret yang dipakai untuk verifikasi JWT)
  3. Copy nilainya
  4. Di Coolify, tambahkan env var: SUPABASE_JWT_SECRET=<paste_di_sini>
  5. Redeploy

  Setelah itu, semua endpoint seharusnya berfungsi normal karena JWT
  verification akan berhasil.

  Juga pastikan env var ini sudah benar di Coolify:
  - NEXT_PUBLIC_SUPABASE_URL — URL Supabase project
  - NEXT_PUBLIC_SUPABASE_ANON_KEY — anon key dari Supabase
  - SUPABASE_SERVICE_ROLE_KEY — service role key dari Supabase
  - SUPABASE_JWT_SECRET — JWT Secret dari Supabase (ini yang missing)
